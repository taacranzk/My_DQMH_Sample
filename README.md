# My_DQMH_Sample
こちらの記事で作成したLabVIEW DQMHで作成したサンプルコードです。

https://stacksequencenotpass.net/dqmh/

作成したLabVIEWバージョン：LabVIEW 2026 Q3

実行に必要な設定
* DQMHのインストール
* DAQ実機かシミュレーションデバイスの設定
* 使用するDAQに合わせてDAQ Channel Setting.csvを編集する。

実行方法
* DQMH Sample Project.lvprojを開き、Application.lvlibにあるMain.viを開く
* Main.viを実行する。

アプリケーションの構造
- Application
    - UI
    - DAQ AI
